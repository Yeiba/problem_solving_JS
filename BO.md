---

### 📘 **Big O Notation Summary Table**


| Big O          | Name         | Explanation Phrase                                                       |
| -------------- | ------------ | ------------------------------------------------------------------------ |
| **O(1)**       | Constant     | "Always takes the same time, no matter the input size."                  |
| **O(log n)**   | Logarithmic  | "how deep or how many steps something needs."                            |
| **O(n)**       | Linear       | "Work grows directly with input size — one step per item."              |
| **O(n log n)** | Linearithmic | "Do logarithmic work for each of the n items — fast sorting level."     |
| **O(n²)**     | Quadratic    | "Work grows with the square of input — nested loops over data."         |
| **O(2ⁿ)**     | Exponential  | "Work doubles with each additional input — explore all possibilities."  |
| **O(n!)**      | Factorial    | "Try every possible order — generate all permutations, extremely slow." |

---

### ✅ Quick Use Cases:

* **O(1)** → Accessing array index, simple arithmetic
* **O(log n)** → Binary search
* **O(n)** → Loop over an array
* **O(n log n)** → Merge sort, efficient sorting
* **O(n²)** → Bubble sort, checking all pairs
* **O(2ⁿ)** → Recursive Fibonacci, subsets
* **O(n!)** → Permutations, Traveling Salesman brute-force
